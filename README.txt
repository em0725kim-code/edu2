국방예산 웹 대시보드

실행: index.html을 브라우저로 열면 바로 사용할 수 있습니다.
설치나 인터넷 연결이 필요하지 않습니다.

부문·회계구분 필터, 프로그램 검색, 차트 단위 선택을 지원합니다.
그래프 위에 마우스를 올리면 상세 수치를 확인할 수 있습니다.
상세 표의 열 제목을 누르면 정렬되며 필터 결과를 CSV로 저장할 수 있습니다.

원본: 상위 폴더의 프로그램별_재원_2026_2027.xlsx
엑셀을 변경한 경우 상위 폴더에서 다음 명령을 실행하고 페이지를 새로고침하세요.
python dashboard/update_data.py
Python 표준 라이브러리만 사용합니다. 원본 엑셀은 수정하지 않습니다.

금액·증감: 억 원. 기본 차트 표시: 조 원.
증감률 = (2027년 - 2026년) / 2026년.
순재원은 음수 차감 항목을 포함합니다.
도넛·예산 지도는 양수 재원만 사용하며, 산점도는 두 연도 예산이 모두 양수인 항목을 사용합니다.
2026년이 0인 항목의 증감률은 계산하지 않습니다.
원문에 표시된 세부 금액의 반올림으로 전체 세부 합계와 PDF 총재원은 소액 차이가 있습니다.
